# Sorayura Homebrew tap

Official Homebrew tap for [Sorayura](https://github.com/AnielloFalcone/sorayura), a native macOS app with system widgets and animated desktop backgrounds.

**Preparation stage:** the first signed and notarized download has not been published yet. This repository currently has no installable Cask. The commands below will become available after that release.

## Install, after the first release

```sh
brew tap AnielloFalcone/sorayura
brew install --cask sorayura
```

If Homebrew requires explicit trust for third-party Casks, review `Casks/sorayura.rb` and authorize only this Cask with `brew trust --cask AnielloFalcone/sorayura/sorayura`, then repeat the install command.

Initial requirements: Apple Silicon and macOS 14 or later. Real-world testing has been on macOS 27.0.1; other macOS versions still need verification.

## Update

```sh
brew update
brew upgrade --cask sorayura
```

The app closes normally during an update. Open Sorayura again after the update. Layouts and preferences are retained. Cask versions include the app build number so new beta builds are detected.

## Uninstall

First disable Open at Login and the Claude connections in Sorayura settings, then run:

```sh
brew uninstall --cask sorayura
```

Uninstalling preserves your layouts, wallpapers and local data. No automatic `zap` cleanup is provided.

If Sorayura is already installed manually, use it to disable login/Claude connections, quit it and move only `Sorayura.app` out of Applications before installing with Homebrew. Keep your Application Support folder to retain your layouts. Re-enable the connections from the Homebrew-installed app.

## Releases

Each Cask will point to an immutable GitHub Release download with a fixed SHA-256 checksum. Packages use Developer ID signing and Apple notarization. Homebrew's normal security checks remain enabled.

The Cask is generated by the [release tooling in the app repository](https://github.com/AnielloFalcone/sorayura/tree/main/native-app/release). The tap and app source use the MIT license.
